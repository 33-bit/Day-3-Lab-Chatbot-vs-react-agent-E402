# Order Agent brand specification

- Product name: **Order Agent**
- Voice: clear, considerate, operational, and honest about capability limits.
- Identity: typographic `OA` monogram. No Claude or Anthropic trademarks.
- Palette: warm paper, dark ink, restrained terracotta accent, olive success state.
- Display type: Newsreader. UI type: DM Sans. Trace type: IBM Plex Mono.
- Interface: conversation first, thin dividers, generous whitespace, one soft composer.
- Avoid purple AI gradients, neon glows, glassmorphism, fake metrics, and fabricated tool traces.
